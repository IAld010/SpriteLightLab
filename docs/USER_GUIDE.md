## 1. 软件简介

Sprite Light Lab 是一个完全在本机浏览器中运行的 2D 精灵工具，主要用于：

- 整理逐帧精灵和精灵图集。
- 自动匹配颜色图与法线图。
- 进行索引色或全彩 Palette Swap。
- 使用环境光、方向光、点光和聚光预览法线光照效果。
- 保存项目库，并导出 PNG、JSON 或 ZIP 项目包。

Windows 单文件版 `SpriteLightLab.exe` 已内置前端资源、.NET 运行时和本地静态服务器。用户不需要安装 Node.js、npm 或 .NET Runtime。

## 2. 系统要求

### 必需

- Windows 10 或 Windows 11，64 位 x64。
- 最新版 Microsoft Edge、Google Chrome 或其他支持现代 Web 技术的浏览器。
- 建议至少 4 GB 内存。

### 推荐

- 支持 WebGL2 或 WebGPU 的显卡和浏览器。
- 1920×1080 或更高分辨率。
- 本地磁盘预留 200 MB 以上空间。

WebGPU 不可用时会自动使用 WebGL2。完整功能面向最新版 Edge / Chrome。

## 3. 下载与安装

### 下载

[下载 SpriteLightLab v1.0.5](https://github.com/IAld010/SpriteLightLab/releases/download/v1.0.5/SpriteLightLab-v1.0.5-win-x64.exe)

1. 将 `SpriteLightLab-v1.0.5-win-x64.exe` 放到任意本地目录。

## 4. 启动与退出

### 启动

双击 `SpriteLightLab.exe` 后，启动器会：

1. 检查是否已有实例正在运行。
2. 优先尝试上次成功使用的端口。
3. 如果没有记忆端口，则尝试 `5173`。
4. 如果端口被占用，依次尝试 `5174–5199`。
5. 启动仅绑定 `127.0.0.1` 的本地静态服务器。
6. 打开系统默认浏览器。

### 主窗口

![中文启动器](images/launcher-zh.png)

可用操作：

| 按钮 | 作用 |
|---|---|
| 打开界面 | 打开当前实际地址；服务未运行时先启动服务 |
| 优先切回 5173 | 5173 空闲时切换回该端口，并提示数据不会自动迁移 |
| 停止服务 | 停止本地服务器，但保持启动器窗口打开 |
| 启动服务 | 重新启动本地服务器 |
| 退出 | 停止服务、关闭托盘并退出进程 |

### 退出

以下操作都会停止服务器并释放端口：

- 点击窗口右上角关闭按钮。
- 点击“退出”。
- 从系统托盘菜单选择“退出”。

只有最小化窗口不会停止服务。

### 单实例

重复双击 EXE 不会启动第二个服务。第二次启动会通知已有窗口恢复并置顶，第二个进程立即退出。

## 6. 端口与项目数据

### 默认地址

```text
http://127.0.0.1:5173
```

### 端口选择顺序

```text
上次成功端口 → 5173 → 5174 → ... → 5199
```

如果所有端口均被占用，启动器会显示明确错误，不会随机使用其他端口。

### Origin 与项目数据

浏览器 IndexedDB、LocalStorage 和 Service Worker 都与 Origin 绑定：

```text
http://127.0.0.1:5173
```

与

```text
http://127.0.0.1:5174
```

是两个独立的数据空间。

因此：

- 为保证项目库可见，应优先使用原来的端口。
- 启动器会记住上次成功端口。
- 只有在 5173 空闲时才建议点击“优先切回 5173”。
- 切换端口前，所有跨 Origin 数据都需要先导出项目。

### 状态文件

```text
%LOCALAPPDATA%\SpriteLightLab\launcher-state.json
```

包含：

- 上次成功端口。
- 上次启动时间。
- 启动器语言。

### 日志

```text
%LOCALAPPDATA%\SpriteLightLab\logs\launcher.log
```

日志超过 2 MB 后会轮转为 `launcher.log.1`。

## 7. 素材导入

### 支持方式

- 选择本地文件夹。
- 拖放文件到应用窗口。
- 选择逐帧 PNG。
- 导入 Aseprite / TexturePacker JSON 图集。
- 导入大图并自动或手动裁切。
- 导入包含颜色图、法线图和项目 JSON 的 ZIP 项目包。

### 法线图自动匹配

应用可识别常见法线图后缀：

```text
_n.png
_normal.png
```

例如：

```text
walk_0001.png
walk_0001_n.png
```

如果无法自动匹配，会进入手工匹配页面。尺寸不一致的图片无法确认配对。

### 推荐目录结构

```text
my-project/
├─ project.json
└─ assets/
   ├─ walk_0001.png
   ├─ walk_0001_n.png
   ├─ walk_0002.png
   └─ walk_0002_n.png
```

## 8. 动画与帧管理

导入后可以：

- 自动按文件名分组为动作。
- 重命名动作。
- 拖拽调整动作顺序。
- 拖拽调整帧顺序。
- 设置帧率、循环和播放方向。
- 逐帧前进或后退。
- 使用曲线编辑器调整帧时序。
- 在时间轴中检查颜色帧与法线帧的同步情况。

建议同一个动作的帧使用统一尺寸和锚点。不同尺寸素材可使用锚点校准功能对齐。

## 9. Palette Swap

### 索引色模式

适合像素画和有限色板素材：

- 读取原图调色板。
- 建立最多 256 色的精确 LUT。
- 保持原图 Alpha。
- 支持多个色板之间切换。

### 全彩模式

适合渐变或非索引色素材：

- 设置颜色规则。
- 调整颜色容差。
- 调整色相、饱和度、亮度。
- 设置整体染色。
- 可叠加多条规则。

### 色板导入导出

支持：

- GPL 调色板。
- HEX 色值列表。
- 多色板管理。
- 撤销与重做。

## 10. 光照预览

支持以下光源：

- 环境光。
- 方向光。
- 点光。
- 聚光。
- 最多 32 个活动光源。

可调参数包括：

- 光照方向与位置。
- 颜色和强度。
- 范围与衰减。
- 法线强度。
- 绿色通道翻转。
- 风格化漫反射。
- 镜面高光强度。
- 光源辅助手柄显示与隐藏。

渲染后端：

- WebGL2：兼容性优先。
- WebGPU：支持的浏览器和硬件上可切换使用。

## 11. 项目库与导入导出

### 项目库

项目会自动保存到浏览器 IndexedDB。可以：

- 新建项目。
- 打开已有项目。
- 重命名项目。
- 删除项目。
- 恢复上次活动项目。
- 从旧版单工作区数据迁移。

### 导出类型

| 类型 | 用途 |
|---|---|
| 当前预览 PNG | 导出的光照预览结果 |
| 透明当前帧 PNG | 不含背景的当前帧图片 |
| 轻量项目 JSON | 引用外部素材的项目说明 |
| 自包含项目 JSON | 内嵌素材数据，便于单文件传输 |
| ZIP 项目包 | 推荐用于完整迁移和备份 |

### 迁移到另一台电脑

1. 在旧电脑的软件中导出 ZIP 项目包。
2. 将 ZIP 复制到新电脑。
3. 在新电脑中导入 ZIP。
4. 确认项目库出现目标项目。

不要只复制 EXE。EXE 不包含用户创建的项目数据。

## 12. PWA 与离线使用

前端支持 PWA：

- 首次成功访问后会注册 Service Worker。
- 缓存应用核心资源。
- 断网刷新后仍可启动已缓存界面。
- 新版本启动后会主动检查 Service Worker 更新。

本地服务器仍必须由启动器运行。PWA 离线能力不等于可以脱离本地服务。

## 13. 系统托盘

右键托盘图标可使用：

- 打开界面。
- 启动服务 / 停止服务。
- 打开日志目录。
- 退出。

双击托盘图标会恢复并置顶启动器窗口。

## 14. 常见问题与排查

### Windows 提示“已保护你的电脑”

这是未签名 EXE 的 SmartScreen 提示。确认文件来自本仓库 Release 且 SHA-256 正确后，可选择“更多信息”→“仍要运行”。

### 双击后页面打不开

1. 确认启动器显示“运行中”。
2. 检查窗口中的当前地址。
3. 点击“打开界面”。
4. 如果服务已停止，点击“启动服务”。
5. 查看 `%LOCALAPPDATA%\SpriteLightLab\logs\launcher.log`。

### 项目库为空

可能原因：

- 当前端口与创建项目时的端口不同。
- 使用了另一台电脑或另一个浏览器。
- 浏览器站点数据被清理。
- 使用了无痕/隐私窗口。

优先切回原端口；如果仍为空，请从 ZIP/JSON 项目包导入。

### 5173 被占用

启动器会自动选择后续端口，并在主窗口显示提示。如果希望切回 5173：

1. 关闭占用 5173 的其他程序或开发服务器。
2. 点击“优先切回 5173”。
3. 阅读数据迁移警告后再确认。

### WebGPU 不可用

应用会自动使用 WebGL2。也可以更新浏览器和显卡驱动。

### 停止服务后浏览器标签是否关闭

不会。关闭启动器后，外部浏览器标签会保留，但页面连接会失败。这是默认浏览器的安全限制。

### 桌面 EXE 图标仍显示旧版本

在桌面按 `F5` 刷新。图标已嵌入 EXE，不需要额外 `.ico` 文件。

## 15. 卸载与数据清理

这是绿色单文件工具，不需要安装程序。

### 删除程序

1. 退出启动器。
2. 删除 `SpriteLightLab.exe`。

### 删除启动器状态和日志

可选：

```text
%LOCALAPPDATA%\SpriteLightLab
```

### 删除浏览器项目数据

需要在浏览器设置中清除 `http://127.0.0.1:5173` 对应的站点数据。删除前建议先导出 ZIP 项目包。

## 16. 隐私说明

- 服务只绑定 `127.0.0.1`。
- 不会连接外部素材处理服务。
- 素材和项目数据不会上传服务器。
- 最终 EXE 运行时不依赖互联网。
- 浏览器项目数据由用户自己的浏览器管理。
